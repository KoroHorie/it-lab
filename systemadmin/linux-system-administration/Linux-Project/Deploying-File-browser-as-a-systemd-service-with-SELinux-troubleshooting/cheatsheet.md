# Project 3 Cheatsheet

---

# Application Deployment

## Download File

```bash
cd /tmp

wget <download-url>
curl -LO https://github.com/filebrowser/filebrowser/releases/latest/download/linux-amd64-filebrowser.tar.gz
```

**Purpose**

Downloads the application into the temporary directory before deployment.

---

## Inspect Archive Contents

```bash
tar -tf linux-amd64-filebrowser.tar.gz
```

**Purpose**

Displays the contents of a compressed archive without extracting it.

**Production Use**

Useful for verifying archive contents before deployment.

---

## Extract Archive

```bash
tar -xf linux-amd64-filebrowser.tar.gz
```

**Purpose**

Extracts the application files.

---

## Move Application

```bash
mkdir -p /opt/filebrowser

mv filebrowser /opt/filebrowser/
```

**Purpose**

Deploys the application into the standard Linux directory for manually installed software.

---

# File Ownership

## Change Owner

```bash
chown root:root /opt/filebrowser/filebrowser
```

**Purpose**

Assigns ownership to the root user.

**Production Use**

Manually deployed software should typically be owned by root unless the application requires otherwise.

---

# Manual Application Execution

## Execute File Browser

```bash
cd /opt/filebrowser

./filebrowser
```

**Purpose**

Verifies that the application itself works before integrating it with systemd.

---

# systemd

## Validate Service Unit

```bash
systemd-analyze verify filebrowser.service
```

**Purpose**

Checks Service Unit syntax before loading it into systemd.

---

## Reload systemd

```bash
systemctl daemon-reload
```

**Purpose**

Reloads all Service Units after creating or modifying them.

---

## Start Service

```bash
systemctl start filebrowser.service
```

**Purpose**

Starts the service immediately.

---

## Stop Service

```bash
systemctl stop filebrowser.service
```

**Purpose**

Stops the running service.

---

## Restart Service

```bash
systemctl restart filebrowser.service
```

**Purpose**

Stops and immediately starts the service again.

---

## Enable Service

```bash
systemctl enable filebrowser.service
```

**Purpose**

Configures the service to automatically start during system boot.

---

## Disable Service

```bash
systemctl disable filebrowser.service
```

**Purpose**

Removes automatic startup during boot.

---

## Service Status

```bash
systemctl status filebrowser.service
```

**Purpose**

Displays:

- Loaded state
- Active state
- Main PID
- Recent logs

---

# Troubleshooting

## View Service Logs

```bash
journalctl -xeu filebrowser.service
```

**Purpose**

Displays detailed logs generated by the service.

**Production Use**

Usually the first command used when troubleshooting failed services.

---

## Check SELinux Mode

```bash
getenforce
```

**Purpose**

Displays the current SELinux operating mode.

Possible results:

```text
Enforcing
Permissive
Disabled
```

---

## View SELinux Context

```bash
ls -Zd /opt/filebrowser/filebrowser
```

**Purpose**

Displays the SELinux security context assigned to the executable.

---

## Restore SELinux Context

```bash
restorecon -v /opt/filebrowser/filebrowser
```

**Purpose**

Restores the default SELinux label based on the file's current location.

**Production Use**

Preferred over disabling SELinux when incorrect labels are detected.

---

```bash

```

**Purpose**

---

# Key Concepts

## `/tmp`

- Temporary download location.
- Suitable for installers and archives.
- Not intended for production applications.

---

## `/opt`

- Standard location for manually installed third-party software.
- Keeps manually deployed applications separate from package-managed software.

---

## Start vs Enable

### Start

```bash
systemctl start filebrowser.service
```

Starts the service immediately.

---

### Enable

```bash
systemctl enable filebrowser.service
```

Starts the service automatically during future system boots.
